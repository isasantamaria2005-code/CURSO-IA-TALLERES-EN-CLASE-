# Talleres en Clase

Repositorio destinado a recopilar los talleres, ejercicios y actividades desarrolladas durante las clases.

## Descripción

En este repositorio se encuentran los diferentes talleres realizados a lo largo del curso, principalmente relacionados con el análisis de datos, programación en Python, economía y herramientas computacionales.

El objetivo es organizar y documentar el trabajo realizado en clase, incluyendo los códigos utilizados, procedimientos, ejercicios y resultados obtenidos.

## Tecnologías utilizadas

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook


## Objetivos

* Practicar programación aplicada al análisis económico.
* Desarrollar habilidades en Python y Pandas.
* Aplicar técnicas de limpieza y transformación de datos.
* Analizar bases de datos y obtener información relevante.
* Documentar los procedimientos y resultados de los talleres.
